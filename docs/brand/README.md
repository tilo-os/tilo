# Repository banner

The light and dark README banners use the Tilo lockup from the website's brand
assets, with the site's paper, ink and primary colours. The wordmark is drawn as
paths; the caption uses the reader's available sans-serif font. Neither banner
downloads a font, script or image.

Keep both variants and the README's alternative text in sync when changing the
wording. These SVGs are text so their changes remain reviewable.
