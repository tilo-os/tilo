## Honest limitations to preserve

- Store explicitly chooses fixed180px cards; keeping that contract can retain overflow. Additive Card/Form APIs require adoption and do not silently migrate Store.
- Raw Store --shots and configured shared FrameHarness capture have different non-Text scale coverage; label the pipeline used.
- Human acceptance and elapsed developer authoring time are not measured. Source decision counts are narrower evidence.
- Safe manual measurement is of the current retained subtree; actual chosen allocation settles through the host. Universal hypothetical re-composition of legacy AppShell topologies is outside this implementation contract.
- Supported origin/decision metadata must reflect real stored data; do not fabricate source paths or universal diagnostics coverage.
- Future collection/detail/document policy expansion, visual editor, every serialized construction path, and a controlled developer productivity study remain architecture rollout opportunities unless separately implemented and verified.
