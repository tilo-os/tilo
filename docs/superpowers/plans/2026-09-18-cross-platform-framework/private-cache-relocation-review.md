### Important — must fix before Task 1 acceptance

1. **Native providers still return String from closures now requiring Failure.** `crates/packaging/install-artifacts/src/cache/linux.rs:991` and `:1126`, and `crates/packaging/install-artifacts/src/cache/windows.rs:1514`, retain `if ... { format!(...) } else { e }` error wrappers. The enclosing provider Result aliases and I/O helpers now use `crate::error::Failure`, so these branches cannot unify: one is String and the other is Failure (or inference forces String and then the preceding `?` conversions fail). Both supported native production paths fail to compile. macOS checks cannot see these cfg-disabled native modules. Preserve the original diagnostic text while returning the original typed error with `with_message(message).with_uncertainty()` in the uncertain branch; retain `e` in the other branch. Do not stringify/recreate the error as generic Failed, which would discard its structural category. Cover with actual Linux and Windows service compilation once suitable toolchains are available, in normal and test-support configurations; all-target checks also exercise the test-only issue below. No compiler diagnostic is claimed from this review because no builds were rerun.

2. **The moved common test hooks are accidentally absent on Windows.** `crates/packaging/install-artifacts/src/cache.rs:20` gates the entire fixture_storage module with `all(unix, any(test, feature = "test-support"))`, while `cache/tests.rs:1` unconditionally imports it and `cache.rs:5` compiles cache::tests on every test host. Simply Unix-gating that import is insufficient: `cache/checkpoint.rs:134`, `:689`, `:693`, `:731` call the moved `fault`/`read_event` hooks under plain `cfg(test)` on Windows too. Make the private helper module available for all unit tests, e.g. `any(test, all(unix, feature = "test-support"))`, keeping its actual DiskProvider/FreshDisk/file-id implementations Unix-gated as they already are. An equivalent small split of portable hooks is acceptable; do not disable Windows tests or widen the public fixture API. Cover with Windows `cargo check -p tilo-install-artifacts --all-targets --locked` with and without test-support, then the preserved Windows suite in its qualified environment.
