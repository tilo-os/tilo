# Private Cache macOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a real private macOS installer-artifact cache using shared held-storage primitives, then qualify its actual native production paths with explicit remaining distribution gates.

**Architecture:** Extend atomic-file's held-directory, observation, lease and explicitly requested namespace durability operations first, preserving existing consumers' admission and behavior. Implement a private macOS provider of the unchanged cache checkpoint protocol and select it in the existing native worker; keep fixture selection explicit and separate. Treat source, compile, native, crash and installed evidence as distinct results.

**Tech Stack:** Rust 1.97.1, edition 2024, existing atomic-file/rustix/libc, APFS, Darwin descriptor-relative filesystem/ACL APIs, existing FileLease, SHA-256 checkpoint protocol, existing authenticated transport and catalog.

**Spec:** [private-cache-macos-design.md](2026-09-18-cross-platform-framework/private-cache-macos-design.md). Read its exact API contracts and source snapshot before this plan.

## Global Constraints

- Native providers, selectors, paths, raw handles and preparation receipts stay within the framework; no SDK expansion exposing them.
- Keep exact `QOSCP001` record bytes, all existing Linux/Windows identity domains, catalog bytes, preference bytes/path and cache root layouts.
- Initial macOS profile is local APFS with ownership enforcement, observable ACLs, exclusive rename and successful qualified directory barriers; include case-sensitive and default case-insensitive APFS.
- Same-UID namespace exclusion is cooperative; retain all ancestry, identity/security snapshots and the root lease through every reader postcheck. No path-reopen authority, Linux cfg widening, fixture substitution or permission repair.
- Missing observation is a failed/open gate. No new ignored tests, weakened assertions or tautological helpers. Native process restart is not power-loss qualification.
- Use plain cargo with `--locked`. Never set `CARGO_TARGET_DIR`, regenerate Cargo.lock, provision tools/devices, use shared stashes, or alter user files/volumes.
- Parent transfers exact product/test paths after extraction Task 3 and any atomic-file owner finish, including only the two manifests' specified feature/test stanzas and the dedicated native test lane. Parent owns commits/integration and independent specification/code reviews; do not stage another owner's changes.
- This plan authorizes no release/signing operation. G02, Windows namespace/profile completion, remaining Linux/Windows S01/S02 migration, L02/L03 and signed installed artifacts remain required program gates.
