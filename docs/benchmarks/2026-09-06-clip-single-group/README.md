Motivation: four UI profiles matched all 4,000 timestamps and show clip_leaf means around 0.99–1.14 ms under instrumentation. For 1..=256 clips, clip_reduce has zero workgroups and clip_leaf has exactly one, yet the existing leaf computes an empty cross-workgroup prefix. Removing that prefix can avoid 33 workgroup barriers (17 reduced-prefix, 16 prefix-bbox). This is a hypothesis, not an expected numerical speedup or proof of p99 causality.
