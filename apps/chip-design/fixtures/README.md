# Synthetic capture contracts

Every JSON file in this directory is an authored **synthetic contract fixture**.
All revisions, source/artifact digests, tool identities, reported checks, outputs
and storage values are placeholders for testing the native import/view/action
contracts. They do not report an executed numerical or hardware experiment.

Named screenshot scenarios alone import these examples; the live app starts
empty. The screenshots label the examples as synthetic. Production imports
validate structure, consistency and declared scope; they do not authenticate or
execute detached artifacts. Original project research receipts belong in the
separate inference-hardware repository, not the first-party app.
