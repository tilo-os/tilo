# qos-format-host

The qOS format-router daemon. Hosts WASM Component Model providers (built to
`wasm32-wasip2`) for file-format codecs and serves a Cap'n Proto RPC interface
over a Unix-domain socket. Builtin codecs (markdown, odt, docx, …) ship the
same Rust source as guest crates; third-party codecs install through the same
registry mechanism.

## Pinned versions (chosen mid-2026)

| Dep        | Version | Why                                                       |
| ---------- | ------- | --------------------------------------------------------- |
| wasmtime   | 46.x    | Stable Component Model + on-disk cache + epoch deadlines. |
| capnp      | 0.26.x  | Latest matching capnp-rpc/capnp-futures.                  |
| wit-bindgen | 0.51.x  | Matches a wasm32-wasip2 toolchain that targets CM 1.0.x.  |
| notify     | 6.x     | inotify-backed registry hot-reload.                       |

The host's Component Model API surface is `wasmtime::component::*` (Linker,
Component, Store, ResourceLimiter). The guest-side bindings are generated by
`wit-bindgen` in the guest crate.

## On-disk layout

- Registry: `~/.config/qos/extensions/format-providers.toml`.
- Socket:   `$XDG_RUNTIME_DIR/qos/services/format-router.sock`.
- Cache:    `~/.cache/qos/wasmtime/` (wasmtime on-disk compilation cache).

## Per-call resource limits

- Memory: 256 MiB linear-memory ceiling per Store, enforced via
  `wasmtime::ResourceLimiter::memory_growing`.
- Wallclock: 10 s, enforced via wasmtime's epoch deadline. A background tokio
  task bumps the engine's epoch once per second; each Store sets a deadline 10
  ticks ahead. An infinite-loop guest gets interrupted with a clean trap that
  the host surfaces as a `resource_limit` `CodecError`.
