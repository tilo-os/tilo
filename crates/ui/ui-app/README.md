# tilo-ui-app

The app runner of Tilo UI, the toolkit every [Tilo](https://code.tilo.so/tilo/tilo)
app and the Tilo shell draw with. For now it holds the runner's integration
tests, which drive apps and widgets through tilo-ui's headless driver.

## Which crate to use

To build an app, depend on [`tilo-app`](https://crates.io/crates/tilo-app).
