# tilo-ui-timeline

The timelines of the Tilo UI toolkit: the calendar's timeline of days, weeks and months
(`ui.Timeline`) and the track timeline of spans and markers along a time axis
(`ui.TrackTimeline`), as retained widgets. It sits above the toolkit (`tilo-ui`); Tilo apps
reach it as `ui::timeline`.

```rust
use tilo_ui_timeline::{Timeline, TrackTimeline};
```
