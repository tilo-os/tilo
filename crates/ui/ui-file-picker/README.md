# tilo-ui-file-picker

The file picker of the Tilo UI toolkit (`ui.FilePicker`): the workspace's places and the files in
them, to open one or several, or to choose where something is saved. It sits above the toolkit
(`tilo-ui`); Tilo apps reach it as `ui::file_picker`.

```rust
use tilo_ui_file_picker::{FilePicker, FilePickerMode};
```
