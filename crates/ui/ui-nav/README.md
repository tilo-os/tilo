# tilo-ui-nav

The window shell of the Tilo UI toolkit (`ui.NavShell`): a sidebar of places, an overview list,
the content and an inspector, side by side while they fit and one at a time with Back when they
do not. Its header row holds the window's controls, notices and the content's actions. It sits
above the toolkit (`tilo-ui`); Tilo apps reach it as `ui::nav_shell`.

```rust
use tilo_ui_nav::{NavPane, NavShell};
```
