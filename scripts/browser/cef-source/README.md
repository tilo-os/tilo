# Chromium composition mutation guard

Native IME cancellation can dispatch `beforeinput`, allow a page to replace a controlled field, then delete the new selection. Direct CEF cancellation reaches the same renderer operation. The patch validates the original edit across script callbacks and preserves newer page/user text, selection, focus and composition. The dictation host's false-success guard and its assertions remain unchanged.

The source pins are Chromium `79460ebecaa5625e57a5fb679a735659e73dc687` (152.0.7977.83), CEF `708dc140cbc3286826a8abef89dc23a44ff9ea72`, and depot_tools `ba8bd9c36425cd550ac6a6c9220808fec73352b7`. `recipe.json` binds all original and candidate source hashes. `reproducible-input-lock.json` binds the resolved Git, CIPD, bootstrap/toolchain and PGO inputs.

## Current patch

`renderer-guard.patch` is the complete revised candidate, SHA-256 `40a39125d44e97d1e0373573fbe77a28ec1254d58f6bb7e2c14eb200614726fc`. Alternatively, apply `tests-only.patch` and `fix-only.patch`; do not apply both forms.

Seven runtime files capture the focused target, editable root, complete editable text, selection/affinity and composition generation. The controller validates that state after `compositionstart`, `compositionupdate` and `beforeinput`. Cancellation validates immediately before the legacy `textInput` default action. Confirmation carries the same validation through `TypingCommand`, which dispatches incremental `textInput` internally, before it restores a retained selection or edits the document. A refused or prevented confirmation also refuses its subsequent caret move.

Retired empty retries cannot delete newer text. A newer composition stays authoritative. Undo ends only the original composition, and lifecycle completion remains associated with its original target. Ordinary handlers that change styles or other unrelated state continue to allow insertion.
