# Developing Tilo

To change an app, the shell or another crate, follow the
[contribution guide](CONTRIBUTING.md), from checkout to pull request. The
[development reference](docs/development/README.md) covers further details.

- [Build prerequisites](docs/development/setup.md)
- [Test a change](docs/development/testing.md)
- [Run the desktop in a window](docs/development/run-desktop.md)
- [Try a change in a VM](docs/development/dev-vms.md)

For reporting problems and submitting changes, see
[CONTRIBUTING.md](CONTRIBUTING.md). For an independent app, use the
[app SDK guide](docs/developers/getting-started.md).
