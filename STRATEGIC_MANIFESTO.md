# Tilo: The Protocol for the Agentic Era
**Strategic Manifesto & Founding Vision**

## 1. The Core Thesis: The Agentic Inflection Point
The history of computing is defined by the interface. For 40 years, the interface has been designed for the biological constraints of humans: eyes, hands, and slow reaction times. This has resulted in a "Pixel-Based" paradigm (Windows, macOS, Web) where interaction is mediated through GUIs, mice, and keyboards.

We are entering the **Agentic Inflection Point**. As the world moves from "Generative AI" (talking) to "Agentic AI" (doing), the human-centric GUI becomes a massive, low-frequency bottleneck. The new era requires a paradigm shift from **Pixels to Protocols.**

**Tilo is the foundational coordination layer for this transition. We are building the interface for the next billion autonomous agents.**

---

## 2. The Problem: The "Legacy Interface" Bottleneck
Current operating systems and applications are fundamentally incompatible with autonomous agency for three reasons:
1.  **Brittle Interaction:** Agents currently interact with the world by "simulating" humans (scraping pixels, moving cursors). This is slow, error-prone, and unscalable.
2.  **Siloed State:** State is trapped inside heavy, monolithic applications. There is no standardized way for an agent to observe, mutate, or synchronize state across different environments.
3.  **Security Deficit:** General-purpose OSs are not designed to sandbox autonomous agents. They lack the granular, action-level capability controls required to run "AI Employees" safely.

---

## 3. The Solution: The Tilo Stack
Tilo is not an "application"; it is a stack of interrelated primitives designed for high-frequency, collaborative, and machine-native interaction.

*   **`tilo-actions` (The Gate):** The core protocol. A structured, typed, and secure registry of capabilities. An agent does not "click a button"; it "invokes an action."
*   **`ui` (The Interface):** A CRDT-native, retained-mode toolkit. It decouples rendering from state, allowing for seamless human-agent collaboration and Wasm-based cross-platform deployment.
*   **`shell` (The Environment):** A Wayland-based compositor that manages workspaces, strips, and sandboxed environments. It provides the "containment" required for safe agentic execution.
*   **`fs` (The Memory):** A P2P, content-addressed filesystem. It allows for instantaneous state hydration and versioned, collaborative data access across distributed agents.

---

## 4. Go-To-Market: The Tiered Expansion Strategy
We do not attempt a high-friction "OS Switch." We win by capturing the layers of the stack incrementally.

*   **Tier 1: The Framework (The Engine):** Win developer mindshare by providing the `ui` and `collab` crates. We become the "Standard Library" for real-time, collaborative applications.
*   **Tier 2: The Desktop Environment (The Bridge):** Package the `shell` for existing Linux distributions. Capture the power-user market and prove the workspace model.
*   **Tier 3: The Operating System (The Destination):** Deploy the full, immutable Fedora Bootc-based OS. Provide the secure, end-to-end environment for enterprise-grade AI fleets.
