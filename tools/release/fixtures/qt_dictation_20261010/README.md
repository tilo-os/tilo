# Historical Qt dictation qualification

These source-pinned fixtures record actual native Qt 6.11.2 editor journeys on
an isolated remote image. They are evidence, not installed applications or a
current-head release gate. No toolkit, model, recording, or binary is distributed
here; signed package receipts retain source URLs, digests and licence metadata.

The compositor was built at `8d8240ba90f2e2ff7e485e2e9c75a592c5f1972a`.
The message-only successor `026841a1d855604e495f39f361c642c819d12d91` has exactly
the same source tree. All full receipts retain the actual binary identities.

`featherpad` qualifies the real signed Fedora editor, including two independent
windows; its earlier incorrect app-ID casing failure remains separate.
`plain` and `rich` pass the complete recorded-speech journey. `line` passes
speech, native ONE Undo/Redo, cancel and focus retirement, then the combined
run fails its later protected-field-active premise. Keep that run failed.
`privacy` independently observes native focus/hints and verifies protected
refusal. It does not perform recognition. The earlier exact-selection failure
is also retained, before any speech worker started.

The raw plain/rich manifests inherited two GTK descriptive labels. The ledger
records that metadata error explicitly; the actual native Qt identity,
presented app ID, qualification scope and binary/source pins distinguish the
subject. No GTK adapter was used for Qt.

The driver copies replace only the owned host build-root prefix with
`${BUILD_ROOT}`. They need the exact historical private runtime and manifests,
and must not be treated as a way to run unverified software or admit a model.
Outputs are JSON-escaped UTF-8 lines: concatenate `lines` to reconstruct the
portable full stdout, including terminal control bytes. The ledger distinguishes
original stdout, portable reconstructed stdout and archive file hashes.

See [the qualification ledger](../../../../docs/architecture/dictation-qt-native-evidence.json)
and [analysis](../../../../docs/architecture/dictation-qt-native-evidence.md).

Byte-identical manifests, drivers and compile outputs share one canonical file.
The ledger retains each historical archive name, its original and portable hashes,
and an explicit `canonical_file` reference. Reconstruct a historical run by
resolving that reference; distinct receipts and failed inner drivers remain
separate. This follows the current repository fixture-layout contract.
# Current-source combined and composite qualification

The `line-current-premise-failed-*` archives reproduce the historical combined
privacy-premise failure at production source
`cb51d4b11a9ca80e16abd775162677b2bdb4da04`. They remain failed.
The `line-current-fixed-*` and `combo-current-*` archives pass the complete
recorded-speech, native editing, protected-field refusal and post-refusal ordinary
field recovery journeys. Native focus, exact protected hints and matching
keyboard/routed/text-input surfaces replace the unsupported protocol-active
premise; all consent and capture refusal assertions remain.

The combo client uses a standard editable `QComboBox` and its actual `QLineEdit`
child, with a content-free native focus observer and no input-method or undo
overrides. Source and binaries are pinned in each manifest. The same signed
private Qt runtime, approved public German recording and ephemeral model witness
are used. No installation, physical microphone access or deployment occurs.

Each logical archive and canonical alias is listed in the ledger's
`current_qualification`. Full stdout remains losslessly encoded as UTF-8 line
arrays, including control characters and original line endings. Only the owned
builder root is made portable as `${BUILD_ROOT}`. Preparation and compiler logs
are retained separately from journey results. The original failed driver and
the standard privacy client reuse their existing canonical archives.
